# Maqueta funcional de MiPasantia

Abrir `index.html` en un navegador. La maqueta no usa servidor ni base de datos: guarda la sesión, publicaciones, favoritos y datos del perfil en el almacenamiento local del navegador.

Incluye una cuenta de demostración:

- Correo: `estudiante@mipasantia.demo`
- Contraseña: `mipasantia2026`

El botón **Restablecer datos** elimina los cambios realizados en esta maqueta y recupera las publicaciones ficticias iniciales.
